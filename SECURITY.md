# Security Policy

## Reporting a Vulnerability

If you believe you've discovered a security vulnerability in a BitBySoft project, please report it responsibly.

Do **not** create a public GitHub issue.

Instead, email:

**[security@bitbysoft.com](mailto:security@bitbysoft.com)**

Include:

* Project name
* Affected version
* Steps to reproduce
* Potential impact
* Proof of concept (if available)

We will acknowledge reports as soon as possible and work with you to investigate and resolve the issue.

We appreciate responsible disclosure and recognise the efforts of security researchers.
